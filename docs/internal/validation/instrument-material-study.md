## Actual comparison entry point

MenuDirector and FileColumn with an explicitly current synthetic session. It never starts transport,
loads user private data, sends work, changes user preferences or moves a device. It renders both
reading sizes, current Glaze and the study palette, over known white and dark backgrounds.
Camera positions move left/centre/right while all material transforms stay fixed. Output is
`Builds/InstrumentMaterialRenders/{variant}/{palette}/{bright|dark}/motion-{0|1|2}.png`.
The final flat-control image uses the exact same production frame/camera/text/palette with only
the physical edge disabled. Actual pixel difference must exceed a small noise floor; a flat or
unconsumed material cannot pass merely because source says it has depth. These frames are a
motion/parallax study, not a claim that a static image proves glass polish.

Checks retain actual text and target minima and measure every rim vertex against its allocated
footprint/depth and strict field. The real mesh must have nonzero thickness. Reading fill must
remain at least98% opaque. Pure palette checks preserve semantic roles and verify minimum text
contrast over the actual linear-light .98 white composite. The former .94 heading composite is
an explicit failing negative at approximately4.05:1 for secondary text. GlazeColor.Over's byte-space
blend is not used as a substitute for the renderer's linear blend.
