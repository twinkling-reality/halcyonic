## Source implementation

Surface.DrawInstrument adds a rounded, inward bevel and real side mesh behind the face. Thickness
is0.012 distance units (5.5mm at a0.46m plane), with no x/y expansion. Text and targets are unchanged.
Only the spatial heading/body consume it; prompt, chosen/focus and outside-text treatments retain
their established semantics. The side uses a filtered, object-fixed fine grain. Neutral specular
and Fresnel edge response use the actual camera and a fixed studio key. This is not real room
reflection, refraction, scene blur or environmental light estimation. There is no animated sweep.
The body and heading retain controlled opacity rather than making words translucent for effect.

The optional fixture-only InstrumentStudy palette uses low-chroma near-neutral reading material
and neutral actions while preserving every state tone and character identity. It cannot be found
as a saved preset. Default and Graphite remain unchanged. The alternative's slightly green cast
is a comparison hypothesis, not an established brand identity.

## Actual comparison entry point

`Halcyonic.XR.Workspace.Editor.WorkspaceRender.InstrumentMaterialCheck` constructs the real
MenuDirector and FileColumn with an explicitly current synthetic session. It never starts transport,
loads user private data, sends work, changes user preferences or moves a device. It renders both
reading sizes, current Glaze and the study palette, over known white and dark backgrounds.
Camera positions move left/centre/right while all material transforms stay fixed. Output is
`Builds/InstrumentMaterialRenders/{variant}/{palette}/{bright|dark}/motion-{0|1|2}.png`.
The final flat-control image uses the exact same production frame/camera/text/palette with only
the physical edge disabled. Actual pixel difference must exceed a small noise floor; a flat or
unconsumed material cannot pass merely because source says it has depth. These frames are a
motion/parallax study, not a claim that a static image proves glass polish.

Checks retain actual text and target minima and measure every rim vertex against its allocated
footprint/depth and strict field. The real mesh must have nonzero thickness. Reading fill must
remain at least98% opaque. Pure palette checks preserve semantic roles and verify minimum text
contrast over the actual linear-light .98 white composite. The former .94 heading composite is
an explicit failing negative at approximately4.05:1 for secondary text. GlazeColor.Over's byte-space
blend is not used as a substitute for the renderer's linear blend.

All palette/field state is restored in finally. Actual Unity shader compilation, scene geometry,
pixel-negative result, motion review and bright/dim passthrough wearer review remain pending.
No image of another immersive app or overlay behavior is established by this fixture.

## Second source iteration after actual rejected proof

The first actual InstrumentMaterialCheck exited0 across both sizes/palettes/backdrops. Root viewed
the images and rejected the aesthetic: a thin bright outline did not read as glass. The bright
white image also exposed missing contrast behind the floating Projects/connection/footer/tab and
identity-caption text. Font angular-size checks did not detect that environmental contrast loss.
No acceptance follows from that earlier clean process. The preserved archive is material-first-rejected.

The second candidate removes the constant all-around optical highlight and adds an analytic
softbox sampled by reflected eye rays across the fixed face. Its camera-dependent face light
is bounded below0.018 additional linear luminance, including the fine coating variation. The
white-composite contrast calculation includes that peak, not just the untouched substrate. This
is still a controlled studio reflection model, not captured room illumination or scene refraction.

Unbacked semantic text groups gain tightly fitted, unoutlined opaque supports measured from actual
glyph meshes, including button icons. Padding is clipped inside the existing owner bounds. The
caption and tab words receive the same contrast support; neither their wording nor hit geometry
changes. This is local legibility support, not a surrounding window or another equal button grid.

Each motion frame now renders a second image with critical text renderers temporarily disabled,
keeping its actual material/background. Image probes compare resolved ink pixels against those
matching background pixels for Projects/navigation, connection/context, Move/Other apps/Minimize,
provenance, Task caption and tabs. At least two changed ink pixels and a resolved4.5:1 core are
required per label. This image probe does not treat antialias fringe pixels as authored text color;
source contrast checks remain separate. The former white floating labels on white fail this test.
Support geometry itself retains the complete strict field checks. Actual second shader/render
execution and motion/aesthetic judgment remain pending.

The analytic studio softbox is authored in the instrument's normalized frame, not fixed to the
world horizon or camera. Reflected world-eye rays are projected into that frame; normalizing each
basis avoids nonuniform plate dimensions distorting reflection angles. This keeps the comparison
meaningful on the actual pitched reading surface while the highlight still responds to real lean.
