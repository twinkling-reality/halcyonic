Archivo publishes no GitHub release, and google/fonts carries only its variable file, so its static cuts come from
the project's repository at the commit above. The six cuts and their roles: Archivo Expanded Regular (Display, a tile's
initials), Archivo Expanded SemiBold (Title), Inter Regular (Body), Inter Medium (Label), Inter SemiBold (Strong),
JetBrains Mono Regular (Mono). Archivo Expanded is width 125; the art direction measured its v2 titles fitting at that
width, so no SemiExpanded cut is bundled.

## What was checked

- Each file is TrueType with no `fvar` table (static), and its name table gives the family, weight and version above
  (OS/2 weight 400 for Archivo Expanded Regular, 500 for Inter Medium).
- Each licence is the SIL Open Font License 1.1 with no Reserved Font Name, so the unmodified files may be bundled
  and redistributed with the app; the copies shipped in `Assets/StreamingAssets/Halcyonic-Licenses/` must equal the
  source licences byte for byte (`KitFontAtlas` checks it on every build).
- `KitFontAtlas` builds a static SDF atlas per face (72 px, padding 9, 1024 square) holding printable ASCII and the
  punctuation the kit and agents' reported text use (an ellipsis, en and em dashes, curly quotes, the middle dot and
  a minus sign), with Liberation Sans as each face's fallback.
- The kit's render page `22-fonts` draws each of the six roles at both text sizes in the face `KitType` gives it, and
  requires every glyph from the face itself, the line whole, outside text in its run with no letter slanted, and its
  contrast in the pixels.
